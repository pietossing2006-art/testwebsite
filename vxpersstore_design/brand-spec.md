# Brand Spec: Vxpers Store (KeyForge)

## Palette (Digital Void / Cyber)
- `--bg`: `oklch(8% 0.02 250)` (Deep Digital Navy/Black)
- `--surface`: `oklch(15% 0.04 250 / 0.6)` (Glassy Navy)
- `--surface-bright`: `oklch(22% 0.05 250 / 0.8)` (Active Card)
- `--fg`: `oklch(95% 0.01 250)` (Off-white / Ice)
- `--muted`: `oklch(60% 0.05 250)` (Dimmed metadata)
- `--border`: `oklch(30% 0.08 250 / 0.5)` (Thin glass border)
- `--accent`: `oklch(70% 0.25 240)` (Electric Blue - Primary)
- `--accent-alt`: `oklch(65% 0.3 300)` (Neon Purple - Secondary)
- `--glow`: `oklch(70% 0.25 240 / 0.3)`

## Typography
- **Display**: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif` (Modern, Wide tracking for tech feel)
- **Body**: `Inter, system-ui, sans-serif`
- **Mono**: `'JetBrains Mono', 'IBM Plex Mono', monospace` (For keys and hashes)

## Layout Posture
- **Gradients**: Subtle radial gradients for background depth.
- **Glassmorphism**: `backdrop-filter: blur(12px)`.
- **Borders**: 1px solid with 0.5 opacity.
- **Radii**: 8px for tech-utility cards, 16px for premium sections.
- **Scanlines**: Global fixed overlay at low opacity (0.03).
