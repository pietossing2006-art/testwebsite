HOME redesign workflow

เลือกทิศทางภาพรวมก่อน แล้วผมจะเขียน spec/plan ตาม Superpowers workflow ให้ชัดเจนก่อนแก้โค้ดจริง

Workflow ที่จะใช้

1

Design spec

สรุปสิ่งที่จะเปลี่ยน: hero, product showcase, category grid, trust/FAQ, responsive และสถานะโหลด/ว่าง

2

Implementation plan

แตกงานเป็นขั้น: ปรับ component structure, polish UI, ตรวจ mobile, build/lint และ browser verification

3

Code + verify

แก้เฉพาะหน้า HOME และ style ที่จำเป็น ไม่แตะไฟล์อื่นที่มีการแก้ค้างใน worktree

คำถามแรก: อยากให้หน้า HOME ไปทางไหน?

คลิกเลือก 1 แบบที่ตรงใจที่สุด หรือพิมพ์บอกผมในแชทก็ได้

VxperS Store

A. Premium Storefront

หน้าแรกดูแพงขึ้น อ่านง่ายขึ้น เน้น hero ชัด, CTA เด่น, สินค้าแนะนำไม่รก เหมาะกับร้านที่อยากให้ลูกค้าซื้อเร็ว

Digital Gear

B. Gaming Arcade

คง cyber/gaming vibe ให้จัดขึ้น: neon, motion, campaign/bundle เด่น เหมาะถ้าอยากให้ร้านดูสนุกและมีพลัง

C. Clean Dashboard

ลดเอฟเฟกต์และจัดข้อมูลให้สแกนง่ายขึ้น เหมาะถ้าต้องการร้านที่ดูนิ่ง น่าเชื่อถือ และโหลดความรู้สึกเร็ว
