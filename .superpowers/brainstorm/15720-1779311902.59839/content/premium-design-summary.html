Approach options inside Premium Storefront

A

Recommended: Balanced Premium

ปรับ hierarchy, spacing, CTA, card polish และ empty/loading states โดยไม่เปลี่ยน data flow หลัก ความเสี่ยงต่ำและเห็นผลชัดที่สุด

B

Visual-heavy Premium

เพิ่ม hero visual ใหญ่กว่าเดิมและ motion มากขึ้น สวยขึ้นเร็ว แต่เสี่ยงรกบนมือถือและอาจต้องจูน performance เพิ่ม

C

Conversion-first

ลดความตกแต่งลงและดันหมวด/สินค้า/เติมเงินขึ้นบนสุด เหมาะกับยอดขาย แต่ brand feel จะนิ่งกว่าแบบที่เลือกไว้

What improves

  • Hero อ่านง่ายขึ้นและ CTA ชัดขึ้น
  • Featured cards ดูเป็นสินค้าเด่น ไม่ใช่แค่ grid ตกแต่ง
  • หมวดหมู่และ bundle ถูกจัดให้สแกนง่ายขึ้น
  • มือถือมีลำดับข้อมูลแน่นขึ้น ไม่เสียพื้นที่ด้านบนมากเกินไป

Trade-offs

  • จะลดเอฟเฟกต์บางจุดที่ทำให้ดู cyber หนักเกินไป
  • ยังไม่เพิ่ม API ใหม่ในรอบนี้ เพื่อให้ scope คุมได้
